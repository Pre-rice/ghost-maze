# 当前架构与产品约定

更新：2026-10-18。本页只说明网站、引擎及试玩技能的架构；现行协作约定在[AGENTS](../AGENTS.md)。交付、诊断和执行过程见[历史档案](archive/README.md)，不作为当前任务。

## 页面与状态

当前四栏目版本已获用户2026-10-15正式发布授权，合入 main；验收与发布边界见[本轮交付](archive/delivery/four-column-workspace-20261015.md)。网站采用原生模块、Canvas 2D，无框架、新依赖或构建步骤。

只有首页：地图／游玩／回放／编辑切换右侧内容，左侧共享地图；电脑左右、手机上下，页面不出现外层滚动条。导航和图标常驻，右框内部滚动。手机两区之间短线可拖动调整比例，双击／Enter恢复默认、方向键微调；比例保存在当前浏览器，各栏目共用，电脑不显示该控件。帮助为宽弹窗，标题和关闭入口固定；GitHub 新标签打开。不存在 maps.html、help.html、editor.html 或兼容入口。

无参数主页默认地图且显示“加载地图以开始”；map 默认游玩，map+replay 默认回放，draft 默认编辑。栏目切换不改URL。进入编辑复制作者原图，不把运行中的鬼位、门态或拾物写进地图；不做编辑再返回时，游玩和回放各自状态不变。实际地图事务（包括编辑撤销／重做）重建新图开局、清空旧回放；只平移、缩放、选工具或看其他层不算编辑。未完成草稿可去地图栏目，进入游玩／回放须校验通过。

2026-10-18规则修正：鬼的前视线读取操作前墙态与玩家位置，后视线读取操作后墙态与玩家位置；只见旧位置仍保留当步追击，但下一步不能穿过刚关闭的门。

运行期物理权威为 MapDefinition 与 GameState；编辑权威为 workspace 中的 EditorDocument，全局 stairs 与各层坐标保持一致。图形工具增加平移，删除选择／复制和工具下方详情／设置。字母门、数字门及按钮在元件旁即时输入；鼠标悬停550毫秒再次打开，移开关闭，触屏点击后保留到点别处。Tab在本次展开时的全图字母池或0～全图钥匙数中循环，池外先回最小值；上次合法输入沿用于同类元件，新字母门默认关闭、再次点击切换初态。中键临时平移、右键临时擦除，松开恢复工具。单向门按指针侧改向；墙／玻璃沿起笔横线或竖线连续绘制。触屏点击容忍轻微抖动，双指导航取消临时笔划；所有工具有触屏入口。

宽高独立1～20，输入直接调整；“适应”将全图各层活动区移至原点、收为最小包络并聚焦，保留各层元件的相对位置。内部8～20容器保持原分享格式。扩容不清空，往四周画地板自动扩展并同步移动所有层元件；裁切直接执行且可撤销。滚轮围绕指针缩放，聚焦回到整个编辑区；改变窗口按相对于聚焦尺寸的倍率保留视野，往返不累积缩小；多层保留楼层切换和半格方向自动配对楼梯；电脑楼层栏位于地图与侧框之间、垂直居中，高层在上、加号在顶、减号在底，轻叠侧框空白边缘；手机位于地图下方、低层在左；纯数字楼层与加减号均为方形，加减号分别添加楼层、删除顶层并同步处理楼梯；新层按当前编辑范围全满，出生／玩家层保留标记。各栏目预留相同的加减控制位置，手机均衡换行，不因切栏目改变地图高度；切层和重建楼层控制后保留键盘焦点。清空元件保留地板，清空方格删除地板和元件；填充方格保留已有元件并按设置宽高补满地板。裁切、清空、填充、删除顶层和改单层均不需确认，全部支持撤销。橡皮擦和右键仅擦墙、门及实体，不能删地板；地板由地板工具移除。新草稿死亡循环在左，探索在右；无常规／自由编辑入口，未改的旧常规图保持原码，实际编辑仍保留原房间结构时保持常规标记，改变该结构则转自由图。

本地列表分地图／进行中存档与编辑草稿，都保存URL和精确到分钟的时间，最近优先。纯地图显示格数／鬼数，进行中存档只显示步数，草稿显示格数／鬼数。全景正方形，多层看出生层；探索地图和探索存档始终按路线有限视野预览，与游玩的全图开关无关。自动草稿仅在无参数主页、未加载任何新图且首次进入编辑时恢复；加载新地图丢弃此前自动草稿，手动保存的草稿不删。

地图栏目唯一随机入口，标题“探索模式”，生命在大小之前，不提供玩法切换；原生成算法保持，空闲时只提前准备生成组件，点击时才生成并编码，复用后台线程，不阻塞界面；等待时反馈状态，防重复提交，关闭取消，失败可重试。精品地图默认收起，当前功能就绪后后台准备全部全景，图片未齐时先完成准备再展开；主题切换也重绘隐藏全景，保存本地记录不重建精品卡片。精品地图按首次交付顺序，显示方形全景与格数／鬼数、小字“由AI参与生成”，不显示评述、钥匙数或参考解法。栏目按精品地图、本地存档、随机生成排列，不再提供加载链接或分享码输入框；地图、存档与回放仍只用地址栏分享和加载。

死亡循环游玩与回放直接全图，无全图按钮与周围鬼数；探索保留，游玩和回放共用同一开关且初始关闭，进入回放不自动开启。方向键保留中心拖动、双指缩放和位置／比例记忆；中心短按使用楼梯，拖动不产生游戏动作。手机方向按键在全图视野左侧，电脑不显示方向按键。标题固定且不加死亡／通关。回放小标题只写游戏模式，栏目无求解、随机或重置；求解入口同标签进入回放，可返回来源及原结果区。地图按活动格包络铺满画布并居中；电脑端宽高都不超过6×6的小图统一按6×6的格宽显示（编辑器“聚焦”与“适应”同规则），超过6×6或手机端仍按实际跨度铺满。

## 唯一地图形状

```js
{
    width, height,                    // 8～20
    editorMode: 'regular' | 'free',
    gameMode: 'exploration' | 'death-loop',
    initialHealth,                    // 探索生命，默认 5；无体力
    multiLayerMode, layerCount,        // 1～10 层
    layers: [{
        hWalls, vWalls, activeCells,
        ghosts: [{ x, y, id }],
        items: [{ x, y, type: 'key' }],
        buttons: [{ x, y, direction, letter }],
        endPos, customStartPos
    }],
    stairs: [{ x, y, layer, direction: 'up' | 'down' }]
}
```

各层只保留一份数据，恰有一个出生点；regular 的默认出生点经装配写入第零层，free 明确设置。允许每层一个终点，至少一个终点才可游玩或分享。鬼顺序保留，不按压缩需要重排。

既有 JSON 可从单层顶层结构或一致的第零层副本接入，但不能猜测冲突。若顶层与第零层不同，或层内楼梯与全局楼梯不同，严格拒绝。保留原件，在总目录说明，不擅自覆盖一份。

所有游玩、编辑导出、AI 和分享入口使用 `validateMapData`。门和玻璃仅能在两侧都为活动格的内部墙段上；外圈及虚空接壤始终显示为实墙，不能通过编辑放置机关，非法原始输入明确拒绝。EMPTY边界沿用既有隐式墙表示以保留合法旧码与操作码校验；静态装配防止遗留边界机关。无终点的机制单元仅在显式 `requireEnd:false` 的研究入口允许。数字门钥匙要求为无符号 32 位整数；探索生命为 1～4294967295。

## 墙体与机制

横墙为 `(height+1)×width`：`hWalls[y][x]` 是格子上墙，`hWalls[y+1][x]` 是下墙。竖墙为 `height×(width+1)`：`vWalls[y][x]` 是左墙，`vWalls[y][x+1]` 是右墙。取方向墙复用 `getWallInDirection`。

| 墙类型 | 值 | 玩家行为 |
| --- | --- | --- |
| EMPTY | 0 | 可过 |
| SOLID | 1 | 阻挡 |
| DOOR | 2 | 自由通行，鬼不能过 |
| LOCKED | 3 | 钥匙足够可过，不扣钥匙，门消失为 EMPTY |
| ONE_WAY | 4 | 仅匹配方向可过 |
| GLASS | 5 | 不可过但可视 |
| LETTER_DOOR | 6 | 当前开时可过；按钮切换全部同字母门 |

墙判定用 `WALL_TYPES.*`，非空写 `!== WALL_TYPES.EMPTY`。墙参数分别为 keys、direction、letter 和 initialState；动态字母门另有 currentState。

成功移动、按钮、楼梯都计一步并推进鬼；无效输入不计。按钮依附实墙或活动区边界，必须通过合法性检查，不能以求解成功代替。楼梯必须在相邻层同格有反向配对，同层同格不可重复；空格使用，操作无需区分上下。

鬼争同一格时，操作后仍能看到玩家者优先；最高优先级相同者共同入格，夹击死亡只扣一次生命。编号与列表顺序不参与决定。

玩家与鬼的射线都只通过连续活动格，虚空中断视线，不能隔空追击。鬼依靠同行／同列直线视野，看到后走最短路一步；失去目标后的短暂追踪无持久记忆，通常不巡逻。鬼不能穿普通门、锁门、单向门或玻璃，但能透玻璃看。已开字母门对玩家和鬼的射线均透明，鬼可以通过。配对楼梯格互为相邻格，双方站在两端时即可互见；玩家抵达楼梯口，另一端的鬼当步追来。上下楼时，原层鬼追旧位置，到达层鬼追新位置，各只走一步；本回合刚到楼梯口的鬼不能再跨层。

## 历史、复活与回放

- 唯一有效动作名 U/D/L/R/STAIR；按钮记录真实方向，点击寻路记录逐步操作。物理动作计算成功后，当步立即完成既有复活；死亡不另占状态或步号。游玩、回放、存档共用完成态，无额外复活参数。当步画面按死亡位置显示，死亡位置只按当步局面查表，不写入局面、存档或回放；生命耗尽或出生点被占仍按原规则终止，当步同样停在该步死亡位置。
- 死亡循环当步恢复原图、循环加一，本轮路线重新从零开始；探索死亡扣生命并保留门、鬼、物品与探索。游玩死亡改为弹窗提示：能复活时只能点“复活”继续，无法复活时只提供“重新开始”；撤销仍由栏目通用按钮提供，通关提示旁提供“查看回放”和“查看最优解”。
- 会话记录从本次加载开始的全部动作和重置，撤销可跨重置及每次死亡，重做恢复对应事件；撤销后新事件截断未来。重置只重开当前局，不丢会话历史。
- 分享路线只包含当前局操作，RESET不进入操作码；死亡循环存档只含当前轮，探索存档含整局死亡。临时存档点保存固定路线码，支持单独删除，和保存到本地是两个操作；删除不改变当前状态或已保存的本地记录。
- 保存地图仅写 map；存档 `?map=M&save=S`，S 与 replay 的编码完全一样。加载存档、粘贴存档URL或回放加载当前步，重新建立其所含路线和撤销序列，不继承加载前的旧会话／临时点。随后进行有效操作或撤销／重做／重置时，URL只保留 map。
- 操作持久，局面是可重建缓存：每32步锚点、初态与当前态、近期局面和16MiB预算；不删除操作省缓存。没有账号、服务器存档或真人反馈自动上传。
- 回放栏目随时查看本局路线，死亡循环刚重生而尚未操作时可看上一轮致死路线；切换栏目保留各自进度。求解外部路线用 map+replay，默认暂停，五档速度和跳步。空格播放／暂停，左右或A/D前后步，上下或W/S调速度；空路线不会自动重复播放。
- 所有栏目1/2/3/4切换；游玩／编辑 Ctrl+Z撤销、Ctrl+Y或Ctrl+Shift+Z重做、Ctrl+S存档点／草稿；Mac可用Cmd，文字输入保留原编辑行为。编辑空格回出生层，游玩空格先回玩家层再按实际站位使用楼梯；回放仍为空格播放／暂停。编辑中键／右键临时工具、F聚焦、滚轮缩放均在帮助中说明。
- 探索全图开关只影响显示，不污染探索；死亡循环全图也不改探索记录。加载URL依据该路线重建探索，不迁移此前别轮、别图的观察。

## 分享与错误处理

完整协议见 [docs/share-codes.md](share-codes.md)。地图码与操作码无格式版本，无旧码解码器或启发式兼容。当前码为 Base64URL，无末尾等号；是否压缩和内容表示由控制位确定。

生成先完整校验，再编码并解回核对；非法类型、悬空按钮、楼梯冲突、数值超界、截断或多余尾数据干净失败。内部位流非法统一抛 RangeError，上层返回可显示错误，不产生 NaN 或死循环。

其它消费者通过本体公开模块复用唯一规则，接入和兼容核验由对应消费者仓库维护。本仓的求解、回放与试玩包均直接使用 GameLogic；搜索索引、队列和启发式不承担物理裁定。

常量使用 `constants.js`，localStorage 经 `safeGet/safeSet`，prompt 经 `askForInput`。历史证据与导入工具不是运行时死代码，不能因旧规则字段而擅自删除。

## 地图与生成

首页随机生成固定探索，仍为原单层DFS加随机点，不保证可解或谜题质量。求解从地图初态出发，无伤无复活，目标为有效动作T最少；始终使用共同GameLogic。小图用BFS，大图用有一致乐观距离下界的A*，收齐全部最短前继；无鬼图只需一条已证明最优的路线代表唯一鬼轨迹。

不同解法按所有层每步可见鬼位归并，保留什么时候动和停，不按编号或列表排列区分。完整物理状态仍含玩家、钥匙与门；鬼轨迹只在最短前继图上归并，不直接合并搜索局面。回放只为代表路线生成，最短步数与整理进度分别展示；预算耗尽自动继续，不提供暂停求解入口，错误可重试。结果在栏目内显示最优步数和逐行回放链接，无弹窗；缓存绑定地图与内容锁，实际改图失效。精品地图预置完整核验结果，任意图的静默求解有预算，困难图仍可能需要等待，不能承诺所有图秒解。

鬼寻路缓存按静态层、权威墙态和目标格分组，不写入物理局面；保留上右下左的原等长路选择。历史地图数量与当时验收数字仅在[对应交付记录](archive/delivery/four-column-workspace-20261015.md)保留，不作为现行数量。

网站入口、状态或分享协议变更时检查完整校验、编码往返及真实动作重放。浏览器集中验收规则和交互变更；地图成果的接收与维护按 AGENTS 执行。

golden 仍在 `test/golden/`；更新应保留规范地图与当前码闭环、逻辑快照，不沿用旧码兼容断言。历史作品、证据和真人原录制保留，迁移结果另存。

## 首次加载

先显示静态界面，按当前URL载入游玩／回放／编辑逻辑；当前功能就绪后利用空闲时间静默准备编辑、帮助和求解。精品图结果直接查核验缓存，未知图由单 Worker 后台计算；精品全景预加载，展开前完成准备。后台准备完后切栏目无需下载或重新加载地图，不为等待求解阻挡游玩。

历次渲染、方向控制与编辑交互的调整见[改进交付](archive/delivery/four-column-refinements-20261015.md)，历史按钮排列不替代现行界面约定。
