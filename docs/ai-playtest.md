# AI自主试玩技能

2026-10-15。手动调用，普通ChatGPT聊天优先、兼容Codex。一次调用自主试玩，交付过程、关键发现、评价、感受与回放；不通过程序搜索通关路线。站点预览现已获用户发布授权；本功能不部署独立服务，后续体验优化等待用户反馈。

## 使用与交付

技能唯一来源：[ghostmaze-playtest](../.agents/skills/ghostmaze-playtest/SKILL.md)。安装、调用和执行条件见[使用说明](../.agents/skills/ghostmaze-playtest/README.md)。默认规则已知、地图答案未知；探索规则模式不读取[规则文件](../.agents/skills/ghostmaze-playtest/references/rules.md)。同一对话可运用亲自获得的经验，不伪装失忆。

原生JavaScript资产包含由本体生成的引擎，无DOM、Node、网络或安装依赖；小型兼容层补充Base64和克隆等标准能力。模型只获得过滤后的文字局面，不返回隐藏鬼位、编号、意图、潜在分支或参考答案。独立目标模块只在最短挑战行动前返回已证明的步数；最优路径不返回，行动后禁止查询中途距离。

完整输入流保留撤销掉的尝试、死亡、重置、存档、笔记；当前局面由共同引擎重建。当前路线以正式站回放交付，完整记录以AI试玩文件保存，不写入真人反馈、训练库或地图集。无法通关、目标未知、平台中断都分别如实说明。

## 维护

技能随批准发布的站点版本同步打包；历史安装包和演练原件保存在交付目录的1.0.0子目录。引擎以本次交付版本固定；导入不同版本记录明确拒绝。之后机制升级需重打包并复验，不能中途静默换规则。

```sh
node scripts/package-playtest.mjs
node scripts/package-playtest.mjs --check
node scripts/package-playtest.mjs --output /实际交付目录
npm test
```

打包从src/core与必要模块读取唯一源码，生成技能内资产和逐文件哈希；不手写第二套规则，不新增网站构建步骤或依赖。目标证明复用本体BFS和GameLogic，仅返回status与steps。统一验收仍从同级AI仓运行`npm run cloud:check`。不因增加skill改物理内容锁。

只有实际完成普通ChatGPT的安装、资源装载、连续操作和恢复链路，才能声明该端通过；受限V8／Node验收与账号端安装验收分开报告。若当前环境无法直接安装到普通聊天账号，不隐瞒这项缺口，也不自行上线远程服务代替。

29项技能专项检查、本体20个测试文件、AI102项参考检查与4个旧工具测试文件、共同内容锁、2份原始种子及11个HTTP入口全部通过。安装包脱离仓库后可独立运行，目标模块只返回步数，受限JavaScript跨执行保存和恢复通过。

在本次聊天的JavaScript执行器中，模型逐步选择动作，工程样例G1-demo以12步通关，中途使用恢复码接续，末局与正式本体回放相同。未调用程序选择通关路线；并行工程检查在后段带入了目标步数，已记入hint笔记，不能把此轮称为完全无提示盲评。报告不强行宣称出现顿悟。
