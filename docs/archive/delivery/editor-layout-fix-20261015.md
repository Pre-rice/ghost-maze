# 多层显示与编辑布局修正

日期：2026-10-15。只更新[独立预览](https://ghostmaze-ui-preview-20261012.prerice.chatgpt.site)，正式站保留原版，主线训练暂停。沿用预览分支以免未认可样式触发正式部署。

## 逐项落实

| 用户要求 | 当前结果 |
| --- | --- |
| 楼层只写数字，加减号在两侧 | 地图底部显示“− 1 2 … ＋”；新增层填满当前范围，减号删顶层，空格回出生层 |
| 修复多层显示错乱 | 已复现范围外悬停导致绘制异常、偏移累积；修正四边越界，连续切层、缩放和栏目切换后图像保持 |
| 桌面侧框左移、略窄，左右留白相等 | 侧框444→420px，正方形地图与侧框整体居中；1440宽左右40px，1920宽左右240px，1024宽左右16px |
| 工具不改大小，每排多一个 | 桌面40px工具每排8个，15个工具两排；390px手机保留38px并排8个，极窄屏自适应且不溢出 |
| 按钮元件图形居中 | 单独下移按钮图形内容，不再只移动整个SVG外框 |
| 更小的纯输入框，无文字／上下键 | 42px输入，保留无障碍名称，数字使用数字键盘；字母及数字Tab池和即时更新保持 |
| 输入框渐显渐隐 | 140ms淡入淡出；从一个元件移到另一个元件停留后正常换框，不被旧关闭计时吞掉 |
| 探索生命与宽高同行 | 初始生命、宽、高、适应放在同一行，窄屏不额外折行 |
| 编辑地图与游玩／回放一样大 | 统一聚焦留白；三种桌面尺寸实际比例和位置一致，保留主动缩放与平移 |
| 紧凑排列、去掉多余分割线 | 缩减编辑行间距，去除编辑设置区分割线；仍保留整体面板边界 |

## 验收与此前遗漏

本轮23项浏览器专项通过，含桌面及触控模拟、320–1920px布局、十层上限、全部四边越界、图像逐字节对照、淡入淡出与Tab、增删层撤销重做。两仓cloud:check通过：本体23文件、AI参考及旧测试、共同规则锁、两个种子、22个HTTP入口和代理检查。新增范围外悬停回归通过。物理规则、分享码和十三图未改，无生成或训练。

上轮23项检查覆盖了规定切层与手势，没有覆盖地图范围外悬停；其通过不能证明不存在这次的绘制缺陷。本轮先记录修复前真实异常和残留偏移，再验证连续操作及图像不变。用户截图中的旧楼层后缀与当前预览源不一致，未无依据归因于缓存；本轮另核对打包文件和源码一致。私有预览由Sites原生部署结果确认，未自动打开侧栏、未检查正式站；浏览器验收使用本地同一源码，未声称真机验收。
