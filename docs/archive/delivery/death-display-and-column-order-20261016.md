# 死亡显示、栏目顺序与通关入口调整

2026-10-16。按用户本轮逐项反馈调整本体网页；十三精品图、物理规则与原种子不变，不设计地图或训练。用户2026-10-13曾要求致死回放画在出生点，本轮按新要求改为死亡位置；旧记录保留。

## 产品结果

- 地图栏目去掉“加载链接或分享码”输入框，顺序改为精品地图、本地存档、随机生成。分享和加载仍只用地址栏（`?map=`、`?save=`、`?replay=`、`?draft=`），精品地图仍在展开时准备全景。
- 游玩与回放的死亡当步画在死亡位置，不再画在复活后的出生点；权威状态仍是既有当步完成态，存档、回放、操作码与步号都不变。死亡位置只按当步局面查表（`stepOutcome.js` 的 WeakMap），不写入共享局面，也不随克隆进入后续步；多层地图的视野层跟着死亡位置，复活后由规则层重新接管。
- 游玩死亡改为弹窗：能复活时只显示“复活”，生命耗尽或出生点被占据时只显示“重新开始”（即重置）；Esc 与方向键在弹窗内无效，弹窗打开时不能操作地图或其他按钮。浏览器后退或载入新 URL 时弹窗正常关闭。URL 加载死亡当步仍是直接进入复活后状态、不弹窗，与之前一致。
- 通关提示“以 N 步通关”右侧增加“查看回放”和“查看最优解”两个按钮，只在通关后显示；前者进入回放栏目看本局路线，后者在游玩栏目打开求解区显示最优步数与解法列表。
- 回放左右箭头改为“上一步”“下一步”。
- 游玩与回放的状态信息间距加大：桌面 20→26px，≤768px 16→20px，≤350px 12→15px。
