# 补角渲染与分享加载修复（2026-10-09）

本次修复针对地图外散落方块、字母门打开后的方块残留，以及分享加载对外部压缩库的等待。只调整渲染与压缩方式，地图、游戏逻辑和分享码 v3 字节布局保持原样。

## 补角为何出现在空白处

原 `drawCorners` 直接检查墙数组，只要格点附近有两段非空墙就填小方块。自由地图的虚空也留有实墙数据，所以主墙绘制已跳过虚空，补角仍会漏出来；字母门打开只改变门态，其墙类型仍为 LETTER_DOOR，旧补角逻辑也把它视作实体。横墙或竖墙的直线接缝同样被计入。

修复后，补角只依附于实际绘出的横、竖墙段：先检查活动格、边界与可见性，再检查门态，最后检查是否相交。打开的字母门、玻璃装饰、纯直线接缝不补块；真实墙角和合成的活动区边界仍补齐。编辑器看 initialState，游戏看 currentState。
