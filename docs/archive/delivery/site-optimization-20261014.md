# 集中站点优化交付

2026-10-14。用户批准此前十一项方案，并进一步确定游戏与编辑器一起加载、保留单向门随指针侧改向和直线绘墙、鬼轨迹保留移动与停顿时序。无需框架；当前专注站点，不设计地图或训练。

| 内容 | 当前行为 |
| --- | --- |
| 单页 | 编辑、游玩、回放同页切换，首次编辑零额外资源请求；地图集、帮助有独立网址 |
| 编辑网址 | 与游玩相同，完整编辑即时更新；旧editor.html入口可用，当前标签刷新恢复编辑 |
| 编辑范围 | 按真实包络居中，独立长宽；扩展保留内容，裁切提示且可撤销 |
| 重排与恢复 | 元件、区域、整图选择移动；撤销重做、本机草稿、相邻层楼梯成对编辑 |
| 触控 | 轻微抖动不丢点击，取消不提交，双指导航不误画；无需鼠标右键 |
| 绘制保留 | 单向门按指针侧改向，拖动沿原墙；墙／玻璃连续沿起始直线 |
| 统一编辑 | 无常规／自由选项，旧图原码和初始揭示保持；修改稿自由编辑 |
| 模式 | 新草稿默认死亡循环且放左边；随机只生成探索，原生成算法不变 |
| 叠放 | 钥匙在鬼上，元件可独立选择和移动 |
| 最优解 | 按逐步鬼位归并，停顿保留，每种一个代表回放；原最短步数保持 |
| 返回来源 | 编辑求解返回编辑与原弹窗；游玩求解返回原进度与弹窗 |

现有码格式保持8～20容器，小图显示／编辑没有8格下限；未完成草稿不伪造出生或终点，地址保留最后有效图，草稿本机保存。只涉及观察窗口的操作不改码。

当前十三图仍是原地图与顺序；本体计算提速不改变物理规则。十三图与旧十五图全部最优动作、107615次物理后继及原回放保持，旧规划653行未改。完整兼容记录在AI[证据](https://github.com/Pre-rice/ghost-maze-ai/blob/main/data/manifests/single-app-compatibility-20261014.json)。

两仓统一验收通过，新回归覆盖开阔20×20的353亿条最短走法直接归并为一种、归途三种节奏保留、A*与原生完整BFS对照，以及编辑范围、裁切、同步楼梯、撤销和取消。40项浏览器专项通过：桌面与触控模拟、同页零请求切换、导航后退、尺寸调整、独立元件、原十三图回放、手机微抖／双指／取消和多层草稿恢复。未用真实手机，未访问正式站或检查部署。

本地桌面空旷空间一次测量：原首批200条回放约563毫秒；新版完整的一种代表解约149毫秒。工作内容正是消除等价赶路组合，但该对照不代表所有图或手机的提速倍数。复杂搜索仍可在预算暂停后继续。
