# 鬼迷宫 (Ghost Maze)

鬼迷宫是一款纯前端迷宫探索解谜游戏。玩家收集钥匙、切换机关门、引动和安置鬼，最终抵达绿色终点。支持单层与多层地图、地图分享和同页回放。

![鬼迷宫游戏截图](https://github.com/Pre-rice/ghost-maze/blob/010d609f52c96bf984056d61cb23227b3100fb2e/ingame-image.png)

## 游玩与制作

- [线上游戏](https://ghostmaze.novic.cc)：2026-10-11 架构升级已上线，主页、独立编辑器和帮助入口已核验。
- 本地首页负责载入、游玩和回放；[editor.html](https://github.com/Pre-rice/ghost-maze/blob/010d609f52c96bf984056d61cb23227b3100fb2e/editor.html) 是独立编辑器，[help.html](https://github.com/Pre-rice/ghost-maze/blob/010d609f52c96bf984056d61cb23227b3100fb2e/help.html) 是完整帮助。
- 首页小导航中的编辑入口另开标签并带上原图；当前游戏和存档保留。编辑器试玩也另开标签，编辑草稿保留。
- 地图和回放入口分别为 `?map=地图码`、`?map=地图码&replay=操作码`。操作码依赖对应地图，不需要录制服务器或账号。
- 分享直接复制地址栏链接；编辑器中合法地图的修改会自动更新链接，未完成地图不保留旧图链接。
- [AI 地图总目录](https://github.com/Pre-rice/ghost-maze-ai/blob/main/docs/ai-map-catalog.md) 集中保存最新有效地图入口、来源和反馈；参考解法与真人路线在折叠区。

## 规则

| 模式 | 碰鬼与复活 | 状态栏 |
| --- | --- | --- |
| 探索模式 | 碰鬼扣一生命；仍有生命可回出生点，保留钥匙、门、鬼位与探索 | 生命、步数、钥匙、周围鬼数 |
| 死亡循环 | 碰鬼死亡；复活重置物理局面与步数，保留探索，循环加一 | 循环、步数、钥匙、周围鬼数 |

默认探索生命为 5，作者可在编辑器调整。体力已取消。成功移动、原地按按钮、使用楼梯各计一步；撞墙和无效空格不计。

两模式死亡都可回到上一个存档点。重置地图会恢复同一地图的初态，清除路线、存档与探索。存档只在当前页面内有效，刷新不恢复进度。撤回后执行新操作会裁掉原未来路线及未来存档。

鬼与玩家同步行动，主要依靠同行或同列的直线视野追捕；看不到玩家时通常静止。失去目标后的短暂移动、门与玻璃的视线差异见完整帮助。周围鬼数覆盖当前层的九宫格，两模式都显示。

数字门要求足够钥匙，通过不扣钥匙，门会消失。字母按钮切换全部同字母门，必须站在按钮格朝其依附墙方向操作。站在配对楼梯格按空格切层。

视野随路线揭示。全图视野仅改变显示，关闭后恢复实际探索，不会永久揭开地图。

## 操作与回放

- 方向键或 WASD：移动或原地按按钮；空格：使用楼梯。
- 点击已探索的可达格：逐步寻路；手机方向面板中心可使用楼梯。
- 主题仅深色、浅色两档，首次按系统偏好选择；电脑隐藏方向按键及其开关，手机保留。
- “随机生成新地图”先设置大小、游戏模式与探索初始生命，再生成。已有地图的作者设置和元素在编辑器修改。
- “回放”进入当前路线，默认暂停、显示全图，支持播放、前后一步、输入步号、滑条和 0.25×／0.5×／1×／2×／4×。
- 关闭回放全图后，沿本路线计算探索。观看和跳步保留原局，“返回游玩”恢复原局。
- “加载该步”必须确认替换当前游玩状态并清除存档。探索模式使用路线产生的视野；死亡循环算新循环，同图时与当前探索取并集，换图不迁移旧探索。

## 开发

原生 ES Module + Canvas 2D，无框架、构建工具或新增依赖。已有 pako 随项目本地提供。需要静态 HTTP 服务，不能直接用 `file://` 打开。

```text
npm test
```

当前 14 个测试文件、148 项检查通过，覆盖规则、编辑器、操作历史、分享格式和回放。游玩、AI 搜索及训练数据制备、回放使用同一份本体规则；AI 用内容锁核验规则基线。
