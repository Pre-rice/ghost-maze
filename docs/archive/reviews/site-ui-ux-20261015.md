# 站点 UI／UX 自检报告

2026-10-15。明确要求的修正更新到[同一预览](https://ghostmaze-ui-preview-20261012.prerice.chatgpt.site)，正式站未改，主线仍暂停。本页只讨论站点体验。用户随后批准除删除撤回外的方案，并追加精品全景预加载；最新执行状态见后续段落。

## 已完成

- 电脑楼层从上到下为“＋、高层至低层、−”；手机保留地图下方、低层在左。两栏恢复原24／14px间距，楼层轻叠侧框空白边缘，不挡内容。短屏十层仍可滚到两端按钮。
- 死亡循环／探索、单层／多层的两侧统一38px高；游玩三排控件统一42px高，排间14px。启用、禁用和选中状态不改变尺寸。
- 随机生成提前准备组件并复用，保留后台计算、取消和重试；只在点击时生成。上轮先解决界面阻塞，却遗漏每次重新加载的等待，本轮针对该开销修正。

旧预览实际连续三次生成约0.74／0.39／0.46秒。相同150ms资产延迟的对照中，旧版约0.59–0.84秒，提前准备后的新版约0.02–0.12秒，生成组件不再重复请求。网络测量会有波动；新版发布后实测三次为78／27／18ms，均为组件准备完成后的测量。

## 自检范围与结果

35项站点专项及两仓统一验收通过。检查九档320–1920px布局、额外短屏十层、深浅主题、四栏目切换、地图／进度／草稿、回放、求解入口、编辑手势、手机方向键拖动与缩放、帮助及键盘、随机生成加载失败／取消／复用。手机为触控模拟，未声称真机验收。核心物理、规则锁、地图集和训练资料未改。

自检通过的是上述已覆盖场景；以下为当时发现与提案，后续批准与执行结果见下；专项通过不等于所有场景都不存在问题。

## 当时的建议与方案

| 优先级 | 发现 | 方案 |
| --- | --- | --- |
| 优先 | 窗口在电脑／手机尺寸间往返后，编辑地图缩放会累积变小；一次测得同窗口下88.5降至73.0。手机八层图切游玩／编辑，地图区高度相差40px | 按相对聚焦比例保存视野，避免累积；手机楼层栏在各栏目统一占位 |
| 建议 | 点楼层后键盘焦点丢失；部分图形工具和二选一按钮缺少读屏选中状态 | 保留切换后的控件焦点，补齐状态提示与键盘操作，不增加可见框线 |
| 建议 | 本地存档、草稿误删后没有恢复入口 | 删除后短时间提供“撤回”，保留当前直接删除方式 |
| 可选 | 手机编辑面板需滚动才能看到草稿；保存时间小字偏淡 | 允许拖动地图与面板分界，临时调整两区大小；略提高次要小字对比度 |

## 后续授权与执行

用户要求精品全景提前准备；不需要删除撤回，其他方案执行。本轮只更新预览。

| 项目 | 执行结果 |
| --- | --- |
| 精品全景 | 收起时准备全部13张，默认仍收起；很快点击时等全景齐全再展开。保存本地记录不清空精品缓存，主题切换也提前重绘。准备期间再次点击可取消展开，加载失败有明确反馈 |
| 编辑视野 | 按相对聚焦尺寸保留倍率与观察中心；电脑／手机／横屏连续往返20次能恢复，手动缩放和平移后也保持 |
| 手机楼层与面板 | 各栏目统一预留控制位置，多层均衡换行，八层不再跳高；拖动中间短线可调两区大小，双击或Enter恢复默认，比例在当前浏览器保存 |
| 焦点与选中状态 | 切层、增删层、变换排列后保留焦点；删至单层时转到单层选项。工具与玩法此前已有读屏选中提示，上轮报告写得过宽，实际补齐单双层选项和当前层状态 |
| 小字 | 提高保存时间、基本信息和数量等次要小字对比，保持层级和字号 |
| 删除 | 按用户决定保持直接删除，没有增加撤回入口 |
