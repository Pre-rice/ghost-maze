# 当前地图码与操作码

更新：2026-10-15。游玩、AI、编辑器与回放共用本体地图校验和规则。本协议已实现，不写格式版本，不考虑旧分享码兼容。旧协议路径只指向本文。

## 入口与保存范围

```text
游玩：/?map=地图码
回放：/?map=地图码&replay=操作码
存档：/?map=地图码&save=操作码
编辑：与游玩同一网址，应用内切换；未完成草稿为 /?draft=草稿码
```

栏目切换不更改网址；无参数主页进入地图栏目。map、map+save 默认游玩，map+replay 默认回放，draft 默认编辑。删除全部旧独立页，不保留兼容入口。save与replay必须在map之后，不能共存；draft不与map／save／replay共存。

地图码包含原图与作者开局设置。操作码只包含路线与对应地图的校验值，缺图或错配不能播放。链接可以直接分享，不依赖 AI 服务、录制编号或账号。

地图不写当前局面、操作、存档、体力、探索、循环、时间、主题、名字和说明。操作不写地图副本、局面、探索、循环、版本、时间或缓存。

## 共用约定

- Base64URL 字符为 A～Z、a～z、0～9、-、_，不带末尾等号。非法字符、非规范尾位及非法长度拒绝。
- 位流高位在前，字段连续排列，字段和层之间不做字节对齐。整份内容末尾最多补 7 个零。
- 可变长无符号整数每组 8 位：低 7 位为数值，最高位说明是否继续；低数值组先写。范围 0～4294967295，最多 5 组，拒绝多余零组和溢出。
- 位置按本层活动格从上到下、从左到右编号。N 个活动格占 ceil(log2 N) 位，N=1 时占 0 位；非活动格及越界编号拒绝。
- 四方向编号：上 0、下 1、左 2、右 3。字母 A～Z 写 0～25，共 5 位，其余值拒绝。
- 原文、deflateRaw level 9、deflateRaw level 9 + RLE 分别比较完整 Base64URL 长度，择短。同长优先原文，再按候选顺序；压缩策略不需要写入控制位，解压只有一种分支。
- 使用已有本地 pako，Node 测试用内置 zlib。解压限制、尾数据校验与往返检查不能为缩码或提速省略。

## 地图码

外层：**1 字节控制 + 地图内容**。控制位 0 为是否压缩，位 1～7 必须为零。

地图码尺寸仍为 8～20，层数 1～10；格式不改。编辑工作区按实际活动格包络显示，宽高可分别从1调整，小图在编码内部保留最小容器。缺出生点／终点的未完成草稿用独立draft码保存和分享，不伪造游玩码。规范地图仅有 layers 一份层定义及全局 stairs，不复制第零层。来源 JSON 的顶层副本或层内楼梯若与权威数据冲突，拒绝生成，不猜测覆盖。

### 内容排列

| 顺序 | 字段 | 位数／条件 |
| --- | --- | --- |
| 1 | 宽减 8、高减 8 | 各 4 位 |
| 2 | 编辑类型 | 1 位，regular=0、free=1 |
| 3 | 玩法 | 1 位，探索=0、死亡循环=1 |
| 4 | 多层、自定义生命 | 各 1 位 |
| 5 | 墙表示 | 2 位，00／01／10，11 无效 |
| 6 | 层数减 2 | 仅多层，4 位 |
| 7 | 初始生命减 1 | 仅自定义探索生命，可变长整数；默认 5 省略 |
| 8 | 出生层 | 仅多层，按层数决定位宽 |
| 9 | 各层内容 | 按层号依次，见下表 |
| 10 | 楼梯配对表 | 仅多层，见下文 |
| 11 | 末尾零填充 | 0～7 位 |

死亡循环不写生命；自定义生命标志在死亡循环中无效，探索不能把默认 5 重复写为自定义值。完整校验要求生命为 1～4294967295。

### 每层

| 顺序 | 字段 | 表示 |
| --- | --- | --- |
| 1 | 全层活动标志 | 1 位；为 0 时追加 width×height 位的按行活动位图 |
| 2 | 终点 | 1 位存在标志；有终点才写活动格编号 |
| 3 | 出生点 | 仅出生层写活动格编号，无重复存在标志 |
| 4 | 鬼列表 | 存在标志；非空写数量减 1，再写各位置 |
| 5 | 钥匙列表 | 同上，不重复写物品类型 |
| 6 | 按钮列表 | 同上，每项为位置、方向 2 位、字母 5 位 |
| 7 | 墙类型 | 横墙逐行，然后竖墙逐行 |
| 8 | 墙参数 | 同一扫描顺序，根据墙类型读取 |

鬼列表保持原顺序，ID 按列表次序重建。不能通过重排鬼缩码。每层至少一个活动格，恰有一个全图出生点；游玩分享至少一个终点。

横墙数量为 (height+1)×width，竖墙数量为 height×(width+1)。虚空墙仅清理已证明不影响移动、渲染或任何活动格直线视野的墙段；处于活动格之间的遮挡不能直接删除。

### 三种墙表示

| 标志 | 表示 |
| --- | --- |
| 00 | EMPTY：0；SOLID：10；其他：11 + 3 位(type−2) |
| 01 | type 直接用 3 位，合法范围 0～6 |
| 10 | type 个 1 后跟 0 |
| 11 | 无效 |

三种表示分别生成候选后比较原文和两种压缩结果。平局按 00、01、10 顺序选择。

参数不另写队列或长度，读完本层类型后按墙扫描依次写：
数字门 keys 为可变长整数；单向门为方向 2 位；字母门为字母 5 位和初始开关 1 位。其他类型无参数。

### 楼梯

多层先写配对数量，再写各对的**下层编号、下层活动格位置**。下层编号按 layerCount−1 的范围决定位宽，位置按该层活动格数决定。

只保存向上一项；解码恢复相邻上层同格向下一项。严格校验两侧均活动、配对、边界层和同层同格唯一。单层不写表。

### 完成检查

生成前校验尺寸、层数据、起终点、实体、墙参数、按钮依附和楼梯；编码后立即解码，核对规范地图与作者设置完全一致。失败返回明确错误，不交付假码。

地图外层及解压后内容限制各 131072 字节。拒绝非法控制位、越界读取、类型／位置非法、不规范整数、非零填充、多余字节及压缩流尾数据。

## 操作码

外层：**1 字节控制 + 4 字节地图 CRC32 + 操作内容**。CRC 高位在前。操作内容可原文或压缩。

五种操作为 U=0、D=1、L=2、R=3、STAIR=4。原地按按钮仍记方向；楼梯不区分上下，地图和站位决定结果。单条支持最多 1000000 个有效操作，解压内容限制 1048576 字节。

CRC32 使用标准多项式 0xedb88320，初值与末尾异或均为 0xffffffff。输入是**严格规范地图以 00 墙表示编码后的未压缩内容**，包括作者设置和整份末尾填零，不包括地图外层控制字节。同图采用不同压缩文本仍能匹配。它用于地图错配检测，不是身份认证。

### 默认：2 位方向与稀疏楼梯表

没有楼梯动作时，四个方向每步 2 位，四步一字节。地图是否多层不增加路线开销，只有实际 STAIR 才写表。

有楼梯时先写数量，再写每次楼梯相对前一次的步号间隔减 1，第一项相对第 0 步。全为可变长整数。例如第 10、70、200 步保存 9、59、129。连续楼梯保存间隔 0。

随后写除去楼梯的 2 位方向流，最后填零。末字节空方向位置数写在控制位，总方向数从剩余字节和填充数推导，总步数为方向数加楼梯数，不重复写长度。

### 备选：五进制

每三步打包为 a×25+b×5+c，范围 0～124，占 7 位；末尾 1／2 步分别占 3／5 位。控制信息说明剩余操作数和末字节填零数，不猜格式。

两种操作表示分别比较原文与压缩，自动选完整码最短。相同长度先保留默认方向表示。

### 控制位

| 位 | 方向与稀疏楼梯 | 五进制 |
| --- | --- | --- |
| 0 | 是否压缩 | 是否压缩 |
| 1 | 0 | 1 |
| 2 | 是否有楼梯表 | 与位 3 一起表示剩余操作数 0～2 |
| 3～4 | 末字节空方向数 0～3 | 位 3 见上；位 4 见下 |
| 4～6 | 位 4 见上；位 5～6 必须为 0 | 零填充位数 0～7 |
| 7 | 必须为 0 | 必须为 0 |

方向表示位 5～7 必须为 0。五进制的剩余数 3 无效。楼梯数量必须非零、位置递增且不超总步数，五进制组必须小于相应 5 的幂，尾位必须为零。

### 规则重建与存档

回放第0步为初态，第N步为第N个有效动作及该步既有复活全部完成后的状态。共同引擎判定死亡，历史层当步执行原复活；复活不占另一步。末步致死直接呈现出生点及复活后的物理状态，无额外参数或可加载的独立死亡状态。生命耗尽／出生点被占仍是原有不可继续状态，但显示位置统一出生点。无效动作明确报告步号，不能静默跳过。

save参数复用操作码全部字节规则和地图CRC。加载即重演全部过往动作，能查看回放并逐步撤销至该路线开局；不继承加载前的会话或重置事件。探索整局保留死亡，死亡循环只保存当前轮。加载后地址含save，开始新有效动作、撤销、重做或重置后去除save。普通栏目切换保留它。

局面缓存、临时存档点、重置事件不写操作码。探索根据该路线重建视野，显示全图不改变它；不会恢复其他轮或其他图的知识。当前会话撤销可跨死亡和重置，属于本次加载的内存历史，保存URL不会携带整个网页会话。

## 未完成草稿码

draft用于独立编辑快照，不修改map或replay格式。复用Base64URL和已有二进制外层压缩择短；内容是UTF-8 JSON的workspace快照（mapData、显示frame、当前层），不含原码副本或运行状态。允许尚未完成起终点和楼梯的草稿；结构、尺寸、元件类型及参数须合法，原文／解压最大1048576字节。进入游玩和求解必须另经完整地图校验。

加载草稿保留层数据和工作范围，不保留上一标签页的撤销栈。完整编辑实时写map，未完成编辑实时写draft；仅视野操作不变URL。草稿本地列表也以此URL保存。自动恢复只发生于无参数首页、尚未载入新地图时的首次编辑，手动草稿列表不受自动草稿丢弃影响。

## 当前样例

《回环》地图码 74 字符，70 步操作码 31 字符。单独方向数据为 18 字节，控制和地图绑定为额外 5 字节。1000 个方向压缩前为 250 字节；可压缩路线还能更短。
