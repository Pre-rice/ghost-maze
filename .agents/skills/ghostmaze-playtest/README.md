# 鬼迷宫试玩

手动调用，让AI读取文字局面、自主选择动作，由同一份游戏引擎推进，最后交付实际过程、关键发现、评价、感受和回放。

默认知道规则、不知道地图答案。可要求“不读取规则”，也可要求“以最短步数通关”；后者只提供已证明的目标步数。一次调用后自主试玩，不逐步等待指示。

本文件只说明安装与运行，不含关卡答案。详细规范在SKILL.md，规则位于独立文件references/rules.md。

## 安装

- ChatGPT：提供独立skill ZIP，以及包含该skill的插件ZIP；使用当前账号支持的技能上传／插件安装入口。安装后显式选择“鬼迷宫试玩”或用@调用。仓库目录本身不会自动安装进ChatGPT。
- Codex：仓库中的`.agents/skills/ghostmaze-playtest`可被发现；在新会话中用`$ghostmaze-playtest`调用，也可安装独立包。默认禁止隐式调用。
- 日常直接执行随包JavaScript，不需要服务、API Key或访问生产站；有Node时可用scripts/play.mjs，无Node时按references/runtime.md在JavaScript执行器中装载同一资产。

普通聊天必须能读取随包脚本并实际执行、返回结果、跨次保存或传递恢复码。代码预览不等同于这些能力；安装是否允许还受账号与工作区配置约束。包与受限JavaScript运行通过，不代表已经在用户的普通聊天账号中安装验收。

## 使用

> 用鬼迷宫试玩这个地图：〈地图链接或分享码〉。

> 不读取规则，自主探索；沿用本对话已有经验。

> 要求最短步数通关，交付过程与感受。

提供map+save时从存档继续，最短挑战给该局面的最少剩余步数。map+replay默认只取地图，不读取回放。新对话不自动加载以前的经验；要延续可以附上经验记录或恢复码。

直接执行的探索规则模式依靠“不阅读规则和实现”的规范，不能形成技术上的源码保密隔离。AI体验也不等同真人反馈，不自动写入训练库或地图集。
