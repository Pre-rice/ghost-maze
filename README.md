# 👻 鬼迷宫 (Ghost Maze)

欢迎来到鬼迷宫！这是一款结合了探索、解谜与生存元素的 2D 迷宫游戏。你不仅需要找到通往终点的方法，还必须设法逃离镇守在迷宫各处的鬼魂。游戏内置了强大的地图编辑器，让你能创造并分享属于你自己的挑战！

**[打开网页即可游玩](https://ghostmaze.novic.cc/)** 。使用方向键或点击格子即可移动。游戏内的「帮助」有完整的规则与操作说明。

## 玩法要点

- 玩家走一格算一步，无效操作不计步。
- 鬼会在玩家移动一步后，追击它看到的玩家。失去视线时，它仍会朝玩家消失的位置再追一步。
- 普通门玩家能通过、鬼不能通过；单向门只能单向通过；数字门需要足够钥匙才能解锁；字母门由对应按钮控制开闭，按下按钮也算一步；玻璃阻挡移动但不阻挡视线；楼梯时纵向通道，可以在不同层间移动。
- 两种模式：
  - **死亡循环**：偏向解谜，全图可见。死亡后会复原地图。目标是以尽可能少的步数通关。
  - **探索模式**：偏向探索，只展示玩家视线探索过的区域，并额外提供周围鬼数的信息。死亡会扣除一点生命并返回出生点。目标是以尽可能多的剩余生命通关。
  
## 进度与分享

没有账号，也没有服务器存档：

- 进度全写在地址里：`?map=` 地图、`&save=` 存档、`&replay=` 回放、`?draft=` 编辑草稿。复制地址栏就是分享。
- 本地存档与编辑草稿只存在当前浏览器、当前网站下。

## 技术

- 原生 ES Module + Canvas 2D，无框架、无构建步骤、无第三方依赖；压缩用仓库内的 pako。
- 静态 HTTP 运行，不能直接双击 `file://` 打开。
- 地图只有一份数据：每层网格 + 全局楼梯表；地图码与操作码都带校验与压缩，格式见[分享码](docs/share-codes.md)。
- 物理规则只有本仓库这一份实现，AI 侧直接调用它，不复制规则。
