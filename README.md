# 👻 鬼迷宫 (Ghost Maze)

欢迎来到鬼迷宫！这是一款结合了探索、解谜与生存元素的2D迷宫游戏。你不仅需要找到通往终点的路，还必须躲避在迷宫中游荡、会主动追捕你的鬼魂。游戏内置了强大的地图编辑器，让你能创造并分享属于你自己的挑战！

**[在线试玩 →](https://ghostmaze.novic.cc/)**　无需安装，无需账号。电脑用方向键或 WASD，手机可点格子，也可以打开方向按键。游戏内的「帮助」有完整的规则与操作说明。

## 玩法要点

- 玩家走一格算一步；每个有效操作之后，鬼也走一格。撞墙、开不了的门、踩不动的格子都不计步。
- 鬼靠视线判断目标：操作前后各看一次。拐弯或关门让它失去视线时，它仍会朝原位置追一步，但不能穿过刚刚关上的门——这正是很多谜题的抓手。
- 门与机关：普通门玩家能过、鬼不能过；数字门需要足够钥匙；单向门只顺箭头方向通过；字母门由同字母按钮成组切换，按按钮本身也推进一回合；玻璃挡人但看得见。
- 两种模式：
  - **死亡循环**：全图可见。死亡当步停在死亡位置，复活后回到出生点、地图恢复本轮初态，循环数加一。
  - **探索模式**：地图逐步揭开，只显示周围鬼数。死亡扣一点生命并回到出生点，已拿的钥匙与门态保留；生命耗尽或出生点被鬼占住时只能重新开始。
- 通关：走到绿色终点即可。多层地图用配对楼梯上下楼，楼梯两端互为相邻通道，跨层也能互见。

## 界面

同一个页面里的四个栏目：

| 栏目 | 用途 |
| --- | --- |
| 地图 | 精品地图、本地存档、随机生成探索图 |
| 游玩 | 移动、撤销／重做／重置、临时存档点、求解最优解 |
| 回放 | 播放、上一步／下一步、调速，也可以加载某一步继续玩 |
| 编辑 | 图形工具画墙、门、按钮、鬼、钥匙、楼梯，保存地图或草稿 |

求解只找无伤、无复活的最优解，并按鬼的逐步轨迹区分不同解法——同样步数的两种走法，如果鬼什么时候动、什么时候停不一样，就当成两个解。

地图集里的每张图都做过合法性校验，并预置了已证明的最优解与全部并列解法。谜题由作者与 AI 反复推敲，只有作者逐张确认后才上架。

## 进度与分享

没有账号，也没有服务器存档：

- 进度全写在地址里：`?map=` 地图、`&save=` 存档、`&replay=` 回放、`?draft=` 编辑草稿。复制地址栏就是分享。
- 本地存档与编辑草稿只存在当前浏览器、当前网站下。

## 技术

- 原生 ES Module + Canvas 2D，无框架、无构建步骤、无第三方依赖；压缩用仓库内的 pako。
- 静态 HTTP 运行，不能直接双击 `file://` 打开。
- 地图只有一份数据：每层网格 + 全局楼梯表；地图码与操作码都带校验与压缩，格式见[分享码](docs/share-codes.md)。
- 物理规则只有本仓库这一份实现，AI 侧直接调用它，不复制规则。
